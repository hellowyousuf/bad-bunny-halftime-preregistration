# Bad Bunny's all-Spanish Super Bowl Halftime Performance: Partisan Meaning Making around a High-salience Sport Event — Pre-registration

This repository is the dated pre-registration of the study, deposited before any caption text was retrieved. Each GitHub release is archived on Zenodo with a DOI.

## What the study is

The study asks how Fox News, CNN and MSNBC (MS NOW from November 2025) framed Bad Bunny's all-Spanish 2026 Super Bowl halftime performance: as a question of who belongs to the nation, or as ordinary partisan conflict, and how the gap between the networks changed from the announcement (September 28, 2025) to the performance and its aftermath (February 8–28, 2026). The data are the networks' closed captions in the Internet Archive TV News Archive.
